# Welcome to piBrick

piBrick is an open-source handheld computer project built around the Raspberry Pi Compute Module family.

The goal is simple: make a small Linux computer that is useful as a daily maker tool while keeping the hardware approachable enough to inspect, modify and manufacture yourself.

## PocketCM5

The current model is **piBrick PocketCM5**. It combines a Raspberry Pi CM5 carrier board, AMOLED display, physical QWERTY keyboard, NVMe support, USB connectivity and a collection of maker-friendly expansion points.

The hardware, drivers and keyboard firmware are published openly. The [piBrick Wiki](https://github.com/amarullz/pibrick/wiki) is the best place to start if you are building one.

## Build, buy or modify

You can buy available parts directly, place a preorder when a batch is open, or manufacture the hardware yourself from the public design.

See the **Buy / Preorder / Build** section on the main page for the current links.
