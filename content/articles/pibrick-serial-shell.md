# piBrick Serial Shell

**piBrick Serial Shell** is a web-based serial console designed to make the built-in piBrick USB serial interface easy to access from a modern browser.

It is useful when the display is unavailable, when debugging boot messages, or when working on low-level hardware and kernel changes.

## Open the shell

Visit [serial.amarullz.com](https://serial.amarullz.com/) and connect the piBrick serial interface from a compatible browser.

The project source is available on [GitHub](https://github.com/amarullz/piBrick-Serial-Shell).

## Why a browser tool?

A static web tool keeps the workflow simple: no custom desktop application is required, and the same interface can be used from a development machine whenever browser serial support is available.
